# Examples

- `example.html`: a finished map of [full-stack-fastapi-template](https://github.com/fastapi/full-stack-fastapi-template). Open it in a browser.
- `overview.png`, `layer.png`, `flow.png`: the screenshots used in the main README.
- `dump.rs`: dev helper, prints a file's syntax tree.
  `cargo run --example dump -- <lang> <file>`
- `calls.rs`: dev helper, prints every call in a file and the function it was matched to.
  `cargo run --example calls -- <repo> <file>`
